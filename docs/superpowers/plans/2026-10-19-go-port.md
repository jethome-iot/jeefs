# Go port Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Implement Core and Record in Go and enforce five-language conformance.
**Architecture:** Native byte views, generated immutable wire descriptors, explicit LE access; harness binaries wrap the public API.
**Tech Stack:** Go standard library, Python codegen, CMake, self-hosted CI.
**Spec:** ../specs/2026-10-19-go-port-design.md

## Global Constraints

- No cgo, unsafe casts, native struct serialization, runtime code generation or external Go dependencies.
- Preserve header v1–v4 and DeviceIdentityV1 wire bytes; no public FS API.
- Keep USID documentation changes separate; leave existing untracked AGENTS.md alone.
- Implementation follows contract and specs only; integration uses existing harness conventions.

## Review Focus

- Caller mutates backing version byte after constructing a view: every operation revalidates before accessing.
- Short and nil buffers: errors, no panic, no partial writes.
- Failed setters: preserve bytes including CRC.
- Reserved record bytes: tolerate reads, clear on explicit serialization.
- JSON metadata null, floats and oversized integers: refuse rather than coerce.
